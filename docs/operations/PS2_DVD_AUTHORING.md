# PS2 DVD-case authoring

This Task 14.3 increment adds `ps2-dvd` to the private authored-packaging workflow. A curated closed DVD keep case supplies reusable housing and three independently bound artwork planes. The application does not infer a case from the platform, invent retail measurements or assume all regional/edition variants share one housing. Curators must supply lawful geometry, a suitable variant name, dimensions and measurement evidence.

## Curate and preview

1. In **Manage release packaging → Create packaging template**, select **PS2 DVD case**. Enter X width, Y height and Z depth in millimeters, their source and a family revision. Mark demonstration dimensions synthetic.
2. Enter **Artwork surface mappings (JSON)** with exactly `FRONT`, `BACK` and `SPINE`. Each mapping uses the actual scene/node/mesh/primitive/material indices, matching diagnostic names, UV0 and the physical art rectangle's width/height. Use distinct targets. The opposite-spine jewel contract is not a DVD contract.
3. Create the draft and **Upload DVD case geometry**, preserving known author, source, license, attribution and restrictions. The private GLB attaches directly to this draft. It does not create a release-artwork or console-model use or authorize public display.
4. Download the attached model and review its closed DVD housing, rounded edges, hinge, seam, latch details, dimensions and artwork mappings. Confirm the review checkbox and mark it ready. The server hashes and validates actual stored bytes before a guarded revision/permission/model-identity recheck. Numeric validation cannot prove historical suitability, ownership or rights.
5. Choose the ready template on an expected release packaging component. Upload artwork separately and explicitly bind front/back/spine. All three bindings determine artwork completeness; an unbound plane stays neutral. Atlas scans need explicit per-surface crops; no paper-net recognition, wrap splitting or implicit image reuse occurs.
6. Open an owned game's **Physical packaging** section and activate **View in 3D**. Geometry-only previews are labeled incomplete. Artwork uses proportional containment, neutral margins and the existing clockwise quarter-turn controls. Keyboard/touch, front/back views, fullscreen, reduced motion, failure fallback and fresh-session cleanup reuse the shared viewer.

These are expected catalog components. Manual `hasBox`, owned presence and condition remain unchanged. Draft replacement and uncertain-upload completion follow the [existing authored workflow](GENESIS_PACKAGING_AUTHORING.md). Ready models, dimensions and mappings are immutable; corrections require a new template revision. Archiving blocks new assignments while retaining existing references. Current administrators curate and upload; current private readers can view. Cleanup protects referenced geometry and artwork.

## Model profile

PS2 uses the existing opaque, single-sided static PBR profile. All housing and artwork must be opaque; bounded alpha blending is available separately for jewel and Switch housing. A transparent outer sleeve/refraction simulation, opening animation and interiors requiring separate artwork are outside this first DVD profile. The neutral art planes sit slightly outside opaque housing to avoid occlusion and z-fighting.

Use a self-contained GLB with one default scene (index 0), meter units, +Y up, positive finite transforms and normalized quaternions. Bounds must match supplied dimensions within 2% or 1 mm per axis, whichever is larger. Source positions/normals/UV0 use float accessors, triangle indices are unsigned and artwork uses exactly two outward-facing triangles forming a full [0,1] rectangle. Artwork UV (0,0) is top left; +V points down. Front faces +Z with artwork right +X, back faces −Z with artwork right −X, and spine faces −X with artwork right +Z. All art is neutral white, non-emissive and opaque. Indices identify targets; names are matching diagnostics. Nested multi-primitive nodes and shared source materials retain the existing per-target resolution/cloning.

Embedded images/textures, external resources, alternate scenes, animation, skinning, morphs, sparse accessors, vertex colors, extensions and extras remain unsupported. Housing color comes from its reviewed original PBR material; no baked labels may appear when artwork is absent. Artwork always references prepared private CATALOG DISPLAY images explicitly.

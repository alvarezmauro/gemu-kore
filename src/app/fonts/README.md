# Bundled fonts

Downloaded unchanged on 2026-10-03 from Google Fonts. These Latin WOFF2 files are bundled for reliable offline development/builds and served by `next/font/local`. Inter is variable; the application exposes weights 400–600. Plus Jakarta Sans is used at 500. Other scripts fall back to the system font stack.

Both fonts use SIL Open Font License 1.1. Full copyright and license notices are preserved in `inter-OFL.txt` and `plus-jakarta-sans-OFL.txt`, obtained from the [Inter](https://github.com/google/fonts/tree/main/ofl/inter) and [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans) Google Fonts source directories.
